# Agricola Korean Gosu

한국어 BGA 아그리콜라 유저를 위한 드래프트 판단 보조 웹앱입니다.

이 프로젝트의 1차 제품은 범용 카드 DB가 아니라 **BGA Arena Draft Memory Coach**입니다. 카드 검색, 통계, 룰링, 전략 태그는 모두 드래프트 중 더 나은 픽을 고르고, 사후에 그 판단을 학습하기 위한 데이터 계층으로 둡니다.

상세 문서는 [docs/README.md](./docs/README.md)에서 시작합니다.

## 핵심 방향

- v0는 BGA Arena 4인 드래프트 환경을 우선 지원한다.
- A~E 전체 카드 중 실제 BGA Arena에서 쓰이는 카드 풀을 기준으로 한다.
- 초반 픽은 broken card, plan anchor, 통계, ADP를 강하게 본다.
- 3~4픽 이후에는 역할 중복, 콤보 방향, 음식/자원 압박, 돌아올 가능성을 더 크게 본다.
- 카드 DB는 추천과 설명을 위한 기반이며, 제품의 첫 화면은 드래프트 판단 흐름에 가깝게 둔다.
- OCR, 실시간 판세 경고, 사후 복기는 v0 이후 확장한다.

## 1차 MVP

```text
BGA Arena 드래프트 중 보이는 카드를 입력하면,
현재 픽에서 추천 카드, 이유, 리스크, 돌아올 가능성, 다음 픽 방향을 설명하는 웹앱.
```

초기 구현은 서버 DB 없이 정적 JSON과 TypeScript 추천 엔진으로 시작합니다.
