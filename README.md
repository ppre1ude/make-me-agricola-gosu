# Agricola Assistant

아그리콜라 보드게임 유저를 위한 카드 검색, 드래프트 분석, 통계, 콤보, 전략 가이드 보조 Web 사이트입니다.

현재는 구현 전 기획 단계이며, 상세 문서는 [docs/README.md](./docs/README.md)에서 시작합니다.

## 핵심 방향

- 한국어 BGA 아그리콜라 유저를 1차 페르소나로 한다.
- 카드 본체와 번역 데이터를 분리해 다국어 확장성을 확보한다.
- Lumin_S 계열 BGA 통계와 한국어 카드 정보를 병합해 드래프트 판단을 돕는다.
- 초기에는 정적 JSON과 Next.js로 빠르게 MVP를 만든다.
- OCR, 사용자 기록, DB, 실물 카드 인식은 MVP 이후 단계적으로 확장한다.

## 1차 MVP

```text
한국어/영문 카드명을 검색하면 카드 정보, 통계 티어, 태그, 기본 콤보를 보여주고,
드래프트 후보 카드를 수동 입력하면 추천 픽 순위를 알려주는 웹앱.
```
