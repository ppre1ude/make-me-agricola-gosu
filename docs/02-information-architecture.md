## 주요 화면

### 홈

홈은 마케팅 랜딩보다 앱 시작점에 가깝게 만든다.

필수 구성:

- 큰 카드 검색창
- 빠른 진입 버튼: 카드 목록, 드래프트 분석, 전략 가이드
- 최근 업데이트 통계
- 인기 카드 또는 상위 티어 카드 일부

### 카드 목록

Agricola Cards의 카드 탐색 경험을 참고한다.

구성:

- 상단 검색창
- 좌측 또는 상단 필터
- 카드 리스트
- 빠른 정렬

필터:

- 타입: 직업, 보조 설비, 주요 설비
- 덱
- 티어
- 태그
- 플레이어 수 조건
- 비용
- 조건
- APR 구간
- ADP 구간
- 통계 신뢰도

정렬:

- 이름
- Rank
- WtdPWR
- PWR
- ADP
- APR
- Plays
- 티어

### 카드 상세

실전 중 한눈에 확인하는 화면이다.

레이아웃:

```text
상단: 카드명, 타입, 티어, 핵심 통계
좌측: 카드 이미지 또는 카드 렌더링
중앙: 효과 텍스트, 비용, 조건, 태그
우측: 통계, 추천 콤보, 관련 가이드, 룰링
하단: 출처, 변경 이력, 관련 카드
```

### 드래프트 분석

드래프트 중 빠르게 사용하는 작업 화면이다.

레이아웃:

```text
상단: 현재 드래프트 라운드와 입력 모드
좌측: 후보 카드 입력 7장
중앙: 추천 순위와 카드별 근거
우측: 내 손패, 태그 분포, 부족한 전략축
하단: 지나간 카드 트래킹
```

입력 방식:

- 카드명 직접 입력
- autocomplete
- clipboard paste
- 추후 OCR 결과 import

### 스캔

초기에는 실험 기능으로 둔다.

흐름:

```text
스크린샷 업로드
→ 카드 영역 후보 crop
→ OCR 또는 vision model로 카드명 후보 추출
→ DB fuzzy match
→ 사용자가 결과 수정
→ 드래프트 분석으로 전달
```

### 전략 가이드

한국어 학습 콘텐츠다.

구성:

- 입문
- 드래프트
- 카드 텍스트 판정
- 경쟁 포인트
- 전략축
- BGA 실전 팁

각 글에는 관련 카드, 관련 태그, 관련 통계를 연결한다.

### 통계 페이지

Lumin_S 계열 통계를 탐색한다.

보기:

- 전체 랭킹
- 저평가 카드
- 과대평가 카드
- 초반 엔진 카드
- 후반 점수 카드
- 조건부 위험 카드
- Elo/Play 특이 카드

분석 예:

```text
PWR 높고 ADP 낮음 = 저평가 가능성
ADP 높고 PWR 낮음 = 과대평가 가능성
Drafted 높고 Plays 낮음 = 조건부 카드
APR 낮고 PWR 높음 = 초반 엔진 후보
APR 높고 WtdPWR 높음 = 후반 점수 후보
```
