# 00 Vision

## 제품 목표

아그리콜라 보드게임을 하고 있는 유저들이 다양한 정보를 한눈에, 쉽게, 빠르게, 정확하게 확인할 수 있도록 도와주는 보조 Web 사이트를 만든다.

이 서비스는 단순 카드 DB가 아니다. 카드 정보, BGA 메타 통계, 드래프트 판단, 콤보, 텍스트 판정, 전략 학습 콘텐츠를 연결하는 아그리콜라 플레이 보조 지식 도구다.

office-hours 이후의 제품 결론은 다음이다.

```text
Product flow: Draft Memory Coach
Data-building flow: Strategy Knowledge Base
```

즉 첫 제품 경험은 카드 검색 사이트가 아니라 BGA Arena 드래프트 중 현재 픽을 판단해주는 코치여야 한다. 카드 DB, 통계, 전략 가이드는 이 코치가 더 좋은 추천과 설명을 하기 위한 기반이다.

## 핵심 가치

### 한눈에

카드 제목을 입력하면 다음 정보를 한 화면에서 확인한다.

- 카드 이미지 또는 카드 렌더링
- 코리아보드게임즈 공식 한글명
- 영문 카드명
- BGA 한글명 또는 alias
- 카드 타입, 덱, 비용, 조건
- 효과 텍스트
- PWR, WtdPWR, ADP, APR 등 통계
- 티어
- 태그
- 추천 콤보
- 관련 전략 글과 룰링

### 쉽게

BGA 같은 온라인 플레이 중에는 스크린샷을 올려 카드 후보를 한 번에 스캔한다.

초기에는 BGA 드래프트 화면 스크린샷을 대상으로 한다. 추후 OpenCV 기반 실물 카드 사진 인식으로 확장한다.

### 빠르게

드래프트 중 고민 시간을 줄인다.

- 현재 후보 카드 중 추천 픽을 빠르게 계산
- 첫 4픽 full visible pack과 마지막 3픽 선택 카드 트래킹
- ADP 기반으로 돌아올 가능성 추정
- 내 손패와 후보 카드의 시너지 표시
- 역할 중복, 부족한 전략축, 조건부 카드 여부 경고
- 다음 픽에서 찾아야 할 역할 표시

### 정확하게

아그리콜라 카드 텍스트의 미묘한 차이를 설명한다.

예를 들어 아래 표현들은 모두 다르게 취급해야 한다.

- 보조 설비 칸을 이용하기 전
- 보조 설비 칸을 이용할 때
- 보조 설비 칸을 이용한 뒤
- 보조 설비 행동을 할 때
- 보조 설비를 낼 때
- 손에 있는 카드를 낼 때

서비스는 단순 번역이 아니라 카드 텍스트의 발동 시점, 조건, 관련 행동 칸, 예외 판정을 설명한다.

## 1차 페르소나

### 한국어 BGA 아그리콜라 유저

- BGA에서 아그리콜라를 자주 플레이한다.
- 카드 드래프트가 승패에 큰 영향을 준다는 것을 알고 있다.
- 영문 카드명, BGA 카드명, 코보게 공식명이 달라 검색이 불편하다.
- 실시간 게임 중 빠르게 카드 강도와 콤보를 확인하고 싶다.
- 초보에서 중급, 중급에서 고급으로 올라가기 위한 전략 글이 필요하다.

## 확장 페르소나

### 글로벌 유저

- 영어, 중국어, 일본어 등 언어 설정을 사용한다.
- 동일한 canonical card id에 대해 locale별 이름과 텍스트를 본다.
- 통계와 전략 해설은 언어별로 점진 확장한다.

### 오프라인 플레이어

- 실물 카드 사진을 찍어 카드 정보를 확인한다.
- 카드명 OCR, 이미지 매칭, 실물 카드 crop 기능이 필요하다.

## 제품 포지셔닝

이 서비스는 다음 세 가지의 결합이다.

```text
BGA Arena Draft Memory Coach
+ 한국어 Agricola strategy knowledge base
+ 카드 검색/통계/룰링 reference
```

Agricola Cards나 ReedStoneFood처럼 카드 정보를 보여주는 기존 사이트가 있지만, 한국어 유저 중심의 드래프트 판단, BGA 통계, 텍스트 판정, 전략 가이드까지 연결하는 서비스는 별도 가치가 있다. v0의 차별점은 카드 정보를 많이 보여주는 것이 아니라, 현재 손패에서 왜 이 카드를 집어야 하는지 또는 왜 강한 카드를 내려놔도 되는지 설명하는 것이다.
