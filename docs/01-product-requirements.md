# 01 Product Requirements

## 제품 범위

서비스는 다음 기능군으로 구성한다.

1. 카드 DB
2. 카드 검색과 필터
3. 카드 상세 정보
4. 드래프트 추천 도구
5. BGA 스크린샷 인식
6. 드래프트 트래킹
7. 한국어 전략 가이드
8. 텍스트 판정과 룰링
9. 통계와 메타 분석

초기 MVP에서는 1~4와 일부 7을 먼저 구현한다.

## MVP 범위

### 포함

- Next.js 기반 웹앱
- 정적 JSON 기반 카드 데이터
- 코리아보드게임즈 공식명과 영문명 검색
- 카드 리스트
- 카드 상세 페이지
- 타입, 태그, 티어, 덱 필터
- Lumin_S 계열 통계 표시
- 웅이님 엑셀 기반 한국어명/효과/티어 매핑
- 수동 드래프트 후보 입력
- 추천 픽 순위
- 추천 이유 간단 표시
- MDX 기반 한국어 전략 글 3~5개

### 제외

- 로그인
- 사용자별 게임 기록 저장
- 실시간 BGA 화면 자동 읽기
- 자동 플레이 또는 액션 추천
- 실물 카드 사진 인식
- 고급 AI 룰링 생성
- 전체 카드 mechanic 완전 구조화

## 기능 요구사항

### 카드 검색

사용자는 카드명을 입력해 카드를 찾을 수 있어야 한다.

검색 대상:

- 영문 카드명
- 코보게 공식 한글명
- BGA 한글명
- alias
- normalized search term

검색 결과에는 최소한 다음 정보가 보여야 한다.

- 표시 이름
- 영문명
- 타입
- 티어
- WtdPWR
- 태그

### 카드 상세

카드 상세 화면은 실전 중 빠르게 확인할 수 있어야 한다.

필수 정보:

- 카드명
- 영문명
- 한글명
- 효과 텍스트
- 비용
- 조건
- 덱
- 타입
- 플레이어 수 조건
- PWR
- WtdPWR
- ADP
- APR
- Plays
- 티어
- 태그
- 관련 콤보
- 관련 가이드
- 룰링 또는 텍스트 판정 메모

### 드래프트 추천

사용자는 후보 카드 7장 또는 현재 손패를 입력할 수 있어야 한다.

초기 추천 로직은 룰 기반으로 한다.

```text
추천점수 =
기본 통계 점수
+ 현재 손패 시너지
+ ADP 기반 우선순위
+ 초반/후반 역할 보정
+ 조건부 카드 위험도 보정
+ 데이터 신뢰도 보정
```

최소 출력:

- 추천 순위
- 카드별 점수
- 추천 이유
- 위험 요소
- 돌아올 가능성 힌트

### 전략 가이드

초기 한국어 정적 가이드 후보:

- 카드 텍스트 타이밍
- 가족 늘리기 경쟁
- 방 늘리기 경쟁
- 화로 경쟁
- 울타리 짓는 법
- 식량 엔진 만들기
- 드래프트 기본 원칙

가이드 글은 카드 DB와 연결되어야 한다.

예:

- 카드 상세에서 관련 가이드 표시
- 가이드 안에서 관련 카드 링크 표시
- 태그 페이지에서 관련 가이드 표시

## 비기능 요구사항

### 빠른 응답

카드 검색과 필터는 실전 플레이 중 사용되므로 입력 즉시 반응해야 한다.

초기에는 정적 JSON을 클라이언트에 로드하고 Fuse.js 또는 자체 normalized index로 검색한다.

### 정확성

통계, 카드 텍스트, 룰링은 출처와 업데이트 날짜를 저장한다.

카드 효과 해석은 confidence를 둔다.

```text
verified
manual
inferred
unverified
```

### 확장성

신규 카드, 신규 통계, 신규 언어가 추가되어도 Card 본체 구조를 크게 바꾸지 않아야 한다.

### 공정성

BGA에서 숨겨진 정보를 추론하거나 자동 플레이를 돕는 기능은 제공하지 않는다.

서비스는 공개 정보 정리, 사용자가 직접 입력한 정보, 스크린샷에서 보이는 정보, 사후 학습 중심으로 동작한다.
