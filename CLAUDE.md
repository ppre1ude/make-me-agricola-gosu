# Claude Code Project Rules

This repo's canonical agent instructions live in `AGENTS.md`.

Claude Code sessions should read and follow `AGENTS.md`, including the skill routing rules for:

- mattpocock skills: `grill-me`, `grill-with-docs`, `tdd`, `diagnose`, `prototype`, `improve-codebase-architecture`, `zoom-out`, `to-prd`, `to-issues`
- gstack skills: `office-hours`, `plan-ceo-review`, `plan-eng-review`, `plan-design-review`, `design-consultation`, `review`, `investigate`, `qa`, `qa-only`, `ship`, `retro`
- Superpowers workflows: `brainstorming`, `writing-plans`, `test-driven-development`, code review, and branch completion when the official Superpowers plugin is installed

Do not vendor external skill repositories into this repo unless explicitly requested.

Project-specific coordination for these three workflow systems lives in `docs/agents/00-agent-operating-model.md`.
